v1.5.2

This is a special release to bring good stuffs (backported) from early releases of v2.x.x to v1.x.x.
As the new release v2.x.x is not ready yet, I thought down-streaming some of the features and bug fixes to keep v1.x.x up-to-date.

> change log from v1.4.0 -> v1.5.2

added:
- added "null" support in http::json
- added a new test (test6) to test "null" implementation
- added a new test (test7) to test http::json::Encode interface
- added http::json::Encode interface to allow custom structs to get encoded using http::json::encode (see test7 for example)

updated:
- updated server to use threadpool (default and only option) [from my testing (while developing v2.x.x) it is quite stable and better]

fixed:
- fixed a major bug in json parsing for array which added trailing commas

removed:
- removed previous implementation to handle clients
- removed threadpool handling from tests/test.py script

known issue:
- library when compiled with clang causes linking issue (macos only with clang++)
